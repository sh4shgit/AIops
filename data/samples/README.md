# LogHub HDFS sample

`HDFS_2k.txt` is the unmodified 2,000-line `HDFS_2k.log` sample from
[LogHub](https://github.com/logpai/loghub/blob/master/HDFS/HDFS_2k.log),
renamed so it can be included in the repository. LogHub describes this as HDFS
system data collected for research; the sample is not a live connection or a
labeled anomaly benchmark. Consult the upstream dataset documentation for
usage terms and citations.
